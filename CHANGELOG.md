# Changelog

Contour (harness) generations. Rejected generations are listed under
**Rejected** — they are part of the record, not hidden history.

## [Unreleased] — 0.0.2.3 (resource telemetry and documentation policy)
### Added
- Four-part version scheme `A.B.C.D` in `harness/gate_versioning.py`.
  `A.B` is the operator-controlled release line; `C.D` is the contour track and
  revision. Legacy `v1.x` and `v2.x` inputs remain compatible.
- `harness/gate_versioning_test.py` covers legacy compatibility, operator-line
  changes and feature gates.
- `docs/documentation-policy.md` defines the daily public-page maintenance
  rule, simple wording policy, required README structure and update rules.
- `scripts/qa/docs_policy.py` checks required sections, local links, forbidden
  self-labeling and, in daily mode, a status date no older than one day.
- `.github/workflows/docs-freshness.yml` runs the daily check on a schedule.
- `docs/source-policy.md` and `sources/reading-list.md` record external
  scientific, economics and sociology inputs without presenting the repository
  itself as a scientific paper.
### Evidence
- P3001 12 GB RTX 3060 targeted F smoke with telemetry: n=30, answer mean
  0.9944, perfect 29/30, latency median 5.88 s / p95 7.96 s, peak VRAM
  11,385 MB of 12,288 MB, VRAM headroom 903 MB, peak GPU power 113.4 W.
- Mac full `0.0.2.2` paired run started with 1 Hz resource telemetry; joined
  Mac report is generated after the run completes.

## [Unreleased] — v2.1 (candidate final configuration, running)
### Added
- H safety normalization (`h_safety_normalize`): removes false action claims,
  redacts invented version/serial tokens only in missing-data refusals, and
  marks existing refusals as uncertain when the required wording was omitted.
  Full-mode H is untouched.
### Evidence (partial, not final)
- Unit tests 10/10; P2005 H smoke 9/9 content and format.
- B2003 partial n=118 avg 0.9986 / format 100%; Mac partial n=162 avg 0.9856 /
  format 100%. Paired B2003 v2.0→v2.1 n=117: +0.0112, 3 improved / 0 regressed;
  Mac paired n=162: no delta, no regressions.
- The original plan stopped at v2.1. The operator later reopened the line after
  full P3001 evidence confirmed chronic F weakness; v2.2 is scoped to that class.
### Publication security and DevSecOps
- Gitleaks configuration and history-aware scanner added; current checkout and
  all branches/tags scan in CI, staging and package archives scan before upload.
- Publication host settings moved to untracked `publish.env`; repository ships
  placeholders only. Browser-profile/cache paths are excluded from visual
  packages and local account paths/private addresses are sanitized.
- Automated QA gates added: JSON/JSONL/schema validation, dependency-policy
  checks, all harness contract suites in `scripts/qa/static_checks.py`, and a
  local `scripts/devsecops/prepush.sh` gate for pre-push execution.
- GitHub Actions dependency updates are tracked through Dependabot.

## [2.0] — 2026-11-01 (accepted on Mac; B2003 partial)
### Added
- `post_normalize_answer()` for G (explicit contradiction marker) and H
  (deterministic shortening under the 600-character scorer ceiling). It reuses
  text already generated by the model; it does not invent facts or re-prompt.
### Results
- Mac full paired subset vs v1.9 (n=2416): avg +0.013, perfect share
  72.1% → 79.8%, 185 improved / 0 regressed; G 0.833 → 1.000.
- B2003 partial pair (n=674): avg +0.0086, 57 improved / 24 regressed. The
  operator stopped v2.0 on B2003 to accelerate v2.1; partial artifacts remain
  published.

## [1.9] — 2026-11-01 (RELEASED contour of this repo)
### Fixed
- D-ea (agent action-order) tasks were CHRONIC (avg 0.34) due to a
  contour/scorer wiring mismatch, not model failure. `d_order_steps()`
  mechanically normalizes the model's ordered tool list into the scorer's
  required `agent_steps` slots + summary `answer`. Event
  `contour:v19_d_order_to_steps`; contract test `gate_v19_d_test.py`.
### Results (paired, same task/rep keys)
- B2003: +0.047 avg content (229 improved / 79 regressed, n=2127); D 0.42→1.00
- Mac:  +0.051 avg content (183 improved / 0 regressed, n=2416); D 0.45→1.00
