# Mission

Strata Autonomous Harness is an open research experiment about **how far a
local AI system can go in building, testing and improving its own software
infrastructure around language models** — and how honest such a system can
be about the journey.

Secondary strategic goal: study **local+cloud cooperation** where the privacy
boundary is enforced locally: cloud intelligence helps solve hard
engineering problems, private data never leaves the user's machines without a
deterministic, auditable policy allowing it. (Status: architecture designed,
implementation scheduled — see `benchmarks/privacy-boundary/README.md`;
nothing is claimed here that has not been measured.)

What this project is **not**: a commercial product, a finished framework, or
proof that any model is "intelligent". It is a documented, reproducible
experiment with an append-only record: hypotheses, prompts, agent actions,
code changes, released and rejected versions, full test results, quality and
speed metrics, machine configurations, telemetry, hangs, stoppages and
regressions.

If an experiment failed, it is a research result and it stays published.
