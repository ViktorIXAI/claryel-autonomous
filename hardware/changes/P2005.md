## CHG-001 — unannounced hardware change detected (2026-11-13 12:13 UTC, status: detected)

**Trigger:** the hourly fleet drift audit (`~/.hermes/scripts/hw-fingerprint.sh`)
reported a fingerprint change for P2005. No operator-announced change existed.

**Monitor diff (fingerprint, previous → current, verbatim):**

```diff
- nvme0n1   1.8T
- nvme1n1   1.9T
+ nvme0n1  1.9T
+ nvme1n1  1.8T
```

Everything else in the fingerprint (GPU PCI ids `10de:2c18` / `1002:13c0`,
RTX 5090 Laptop 615.71.09 / 24463 MiB, 61953 MiB RAM) is unchanged.

**Diagnosis (live re-inventory over SSH, 2026-11-13 12:13 UTC): no physical
change — NVMe instance renumbering after a kernel update.**

| item | previous boot (kernel 7.0.0-38, booted 2026-10-25 22:12 UTC per kernel journal) | current boot (kernel 7.0.0-43, booted 2026-11-13 12:07 UTC) |
|---|---|---|

- Same two drives, same PCI slots (kernel `nvme nvmeX: pci function …` lines,
  boots -1 and 0). Only the `/dev/nvmeX` instance order flipped.
- Cause: kernel `7.0.0-43-generic` installed by unattended-upgrade
  2026-11-12 06:16 UTC; the box rebooted into it 2026-11-13 12:06–12:07 UTC
  (uptime start 12:07 UTC). Probe order between `02:00.0` and `04:00.0`
  changed with the new kernel.

**Impact: none detected.**
- `fstab` mounts `/`, `/home`, `/boot/efi`, `/srv/ds-store` by filesystem
  UUID — device-name order is irrelevant; all four mount points verified
  present at the 12:13 UTC live check (OS+home on the Lexar, ds-store on the MSI).
- Serving resumed unattended: `@reboot` keep-up brought the :8080 serve back
  (server.py + strata engine + strata-vision processes live at the 12:13 UTC check).

**Benchmark comparison:** not applicable — no measurable hardware moved
(identical drives, identical slots, identical GPU/driver/RAM). No re-run of the
cold ladder or contour sweep is required for this entry; fingerprint values
match the pre-change baseline exactly except for the two renamed size lines.

**Passport:** `hardware/inventory/P2005.md` gains a storage row (previously
