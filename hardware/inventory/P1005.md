# Passport P1005 — platform box (board anchor ASUS Z10PA-U8)

P1005 is a **test platform, not a fixed machine**. The published identity is
the chassis + board; CPU, RAM, storage and the compute GPU are versioned test
variables. Every change is recorded as `CHG-NNN` in
`hardware/changes/P1005.md`, and every benchmark below is only valid for the
hardware **state** (S1/S2/…) it names. A result row that does not name a state
predates this convention and must be re-read against the ledger.

## Platform (the anchor)

| field | value |
|---|---|
| vendor/model | server tower, no SMBIOS system name |
| board | ASUS Z10PA-U8, LGA2011-3, C610-class (dmidecode, live read) |
| OS / kernel | Ubuntu 24.04.5 LTS (`noble`), **Server image**, kernel 6.8.0-147-generic; live check 2026-11-03 (host later became unreachable; recheck after power-on) |
| console GPU | onboard ASPEED (BMC-class graphics; kept, never benchmarked) |
| network | wired, negotiated 1 Gb/s full duplex (`ethtool`, 2026-11-03) |
| serving engine | [Strata](https://github.com/Niko1221/Strata) repo v0.2.10, engine 0.1.56 linux-x86_64-cuda12 (prebuilt), OpenAI-compatible :8080; model IQ3_S GGUF 2-part (see model-iq3s.md), max-context 32768 |
| launch config | hardware/configurations/strata-iq3_s-p1005.launch.json (sanitized) |
| role | fleet node / benchmark bench (P1005 label for results rows) — CPU, RAM tier, disks and GPUs are all open swap candidates |

## State S1 — Tesla P100 records (2026-10-20 … 2026-11-02)

First-run cold engine, empty KV, 32 768-token prompt (repo v0.2.9 / engine
0.1.55): prefill 234 tok/s, decode 21.3 tok/s (wall 143 s, acceptance 38/48);
warm ladder decode 22.2–22.5 at 8 k–32 k, prefill plateau ≈220. After porting
the 12 GB-card recipe (`--resident-budget-gib 20` +
`STRATA_UNBUFFERED_LOAD=1` + `--prefill 4096` + `--pool-workers 16` +
`--max-context 32768`): cold ladder prefill 209/269/285, decode 15.6/21.6/26.5
at 2k/8k/16k (warm decode peak 27) — prefill +30–35 %, decode +10–20 %.
Engine-log speed records (raw model, no harness): decode peak 47.2 tok/s;
structured/agent 40.7–43.8 sustained (acceptance 96–100 %); free prose
33.9–37.2; prefill 294.0 at a 16 448-token cold prompt; GPU 45 °C, 33.6 W,
VRAM 15.5/16 GiB resident. Full table: results/p1005-speed-records.md.
Full contour v2.1 series (2421 pairs, same plan/seeds as B2003): mean 0.9414,
perfect 81.7 %, format 99.8 %, 1.41 calls/task, 1127 tok/task, 21.1 s/task;
paired vs B2003 46 better / 118 worse / 2257 ties, mean delta −0.0067 —
quality is hardware-portable, Pascal pays wall-clock (2.7×). Full report:
results/p1005-v21-full.md.

S1 tuning levers (measured, re-confirmed): `--resident-experts` with an
explicit `--resident-budget-gib` (without it `STRATA_UNBUFFERED_LOAD=1` is
silently ignored), `--vram-reserve-mib 960` + `--max-context 32768` (the
262 144-KV reservation starves the expert cache), `STRATA_Q8_SM60=0`,
`STRATA_DENSE_F32=1`. Engine 0.1.55 raised decode ~15→~22 at 16 k–32 k vs
0.1.46/0.1.47 on the same box. Production speed config:
`--resident-budget-gib 25 --memory-limit-mib 28672 --vram-reserve-mib 512` +
`STRATA_ROUTE_PRIOR=1.5` (residency-biased routing doubles prose/worst-case
decode; carries upstream #4402 repetition cost — quality series ran without
it). 60–70 tok/s decode is not reachable on sm_60: IQ3_S decode is
dequant-bound and Pascal has no tensor/bf16 path.

## State S2 — RTX 3060 12 GB (2026-11-02 … 11-03)

Raw speed (no harness, max-RAM config 25/28672, 170 W): quickbench decode
31.4/45.7/46.7 at 2k/8k/16k; prose 39.4/46.4; prefill 448.1 at 16 448 cold.
Under the 20 GiB benchmark config the same card reads prefill 371–378 cold —
the expert-residency budget, not the GPU, moves prefill here.
Contour v2.2 quick (178 tasks, one per task, all 11 cats, `0.0.2.2`,
benchmark config 20 GiB/24576):
Run 1 (170 W, unlock installed but not active): mean 0.9759, perfect 95.5 %,
format 98.9 %, 10.6 s/task (median 8.6), 1.47 calls, 1332 tok/task, 2294 s;
adjusted 0.9851 / 96.6 % excluding the two known G-ve-13/14 capacity rejects;
F returned 1.00 on all ten tasks.
Run 2 (187 W + gpu-unlock active): mean 0.9829, perfect 95.5 %, format 98.9 %,
11.6 s/task (median 9.3), 1.50 calls, 1354 tok/task, 2471 s; paired content
per task 4 better / 4 worse / 170 identical — single-repeat noise. Engine
decode 44.0–44.9 mean, 90.7 peak both runs; GPU peak 169.1 → 182.3 W across
the pair, peak temp 66 → 62 °C, 1995 MHz.
gpu-unlock verdict: card unlocked cleanly (Zagitta 2.0 deb, dkms, legacy BIOS
= no Secure Boot; dmesg `gpu_unlock: unlocked`, PLM writes ret=0) but the
measured Strata effect is ≈0 (cold prefill +1.7 %, decode flat) — IQ3_S
prefill here is bound by expert streaming over DDR4-2133 + PCIe, not tensor
issue rate; the B2003-class +5–11 % does not transfer to this memory tier.
Full before/after ledger: hardware/changes/P1005.md (CHG-001).

## State S3 — Tesla P100 returned (2026-11-03, current)

Same model as S1; driver branch rollback 615→580.196.07 (R615 dropped
Maxwell/Pascal), `modprobe nvidia` reloaded the module **without a reboot**.
Power limit 250 W = factory default=min=max for this card — no headroom to
set. gpu-unlock package remains installed but inert (no
`gpu_unlock.targets=` on the kernel cmdline, so an unsupported card cannot
fail the unlock path at boot). keep-up respawned serve unattended (20 GiB
resident experts, 983 MiB VRAM free). Post-swap sanity ladder (warm, same
script as S1/S2): decode 27.8/37.6/43.9 at 2k/8k/16k, prefill 16k 279.4,
52.7 W at 55 °C — inside the S1 record band, no regression.

**Sensors:** GPU util/temp/power/clocks (nvidia-smi) ✔ · RAM via /proc/meminfo ✔ ·
CPU temp ✔ (nct7904 hwmon; fan5 = GPU fan) · whole-system power ✖ `not_available` ·
CPU package power ✖ `not_available` (server board, no RAPL exposure recorded).
**Configuration history:** the CHG ledger (`hardware/changes/P1005.md`) is the
authoritative sequence; the global table
`hardware/changes/configuration-changes.md` carries one-line rows.

Verify commands: `lscpu`, `free -h`, `dmidecode -t system -t memory` (sudo on
rig), `lsblk -T`, `uname -r`, `lsb_release -ds`, `lspci -d 10de: -nn`,
`nvidia-smi --query-gpu=name,memory.total,driver_version,power.limit`,
