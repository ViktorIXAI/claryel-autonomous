# Passport P3001 — Ivy-Bridge Xeon box, fleet's first local ISA-floor engine build

Live-collected 2026-11-02 (ssh; commands at bottom). Box re-commissioned with an
RTX 3060 on 2026-11-01; the ready-made Strata engine cannot run on this CPU
(AVX2 required), so the engine is compiled locally with the experimental
older-CPU floor — the first applied case of that path in this fleet.

| field | value |

| role | fleet node; serving box (IQ3_S on :8080), benchmark candidate for the older-CPU engine path (P3001 label) |
| vendor/model | HP workstation (DMI system name `not_recorded` at collection; HP subsystem IDs on PCI) |
| CPU | Intel Xeon E5-2697 v2, 12 cores / 24 threads, 2.7–3.5 GHz — Ivy Bridge-EP: **AVX1 only, no AVX2** |

**Video:** the monitor sits on the K620; the RTX 3060 has no connected
connector, so it is compute-only in practice. nvidia-smi and CUDA enumerate the
two cards in different orders; the engine's GPU auto-pick skips the unsupported
K620 on its own — do not pin a `gpu` index in the profile.

**First ad-hoc numbers (2026-11-02, IQ3_S, 60-token prompts, not a ladder yet):**
prefill 10.9 t/s cold first request, 13.7–19.8 t/s warm; decode 10.0 t/s cold,
19.6 t/s warm (draft acceptance via MTP on); decode expert-cache hit rate
54.7 % → 71.9 % warm; the engine places 4.8 GiB of expert cache in VRAM against
46.8 GiB of experts (file tier reads dominate on a cold cache). Full cold/warm
ladder queued (`not_recorded` pending).

**Qwen3.6-35B-A3B UD-Q4_K_XL experiment (2026-11-02, published as a negative
result):** file 22,853,663,008 bytes, sha256 `55983c5a…fe9f1` (matches the
upstream digest). The q36 engine path keeps every expert it can in VRAM and
holds the whole expert set (18.75 GiB measured) in host memory — placement
completed in 156.5 s with 36/256 experts per layer resident (2.64 GiB VRAM),
but on 15.5 GiB RAM the first attempt was OOM-killed by the kernel (exit 137,
dmesg-confirmed). With a 24 GB swapfile the engine survives and runs in heavy
thrash (swap ≈ 10–13 GiB in use, iowait 83–87 %): bench numbers below confirm
it is not practically usable on this box; upstream's own floor for this size
is 32 GB RAM. See history/failures/failures.md.

**Configuration history:** shipped without a compute GPU; RTX 3060 added
2026-11-01; driver 615.71.09 (Maxwell-unsupported, K620 unclaimed) replaced
2026-11-02 by 580.196.07 so both cards claim the NVIDIA driver. Engine dir
`engine-avx` alongside a prebuilt `engine/` kept for reference (refuses to
load on this CPU).
