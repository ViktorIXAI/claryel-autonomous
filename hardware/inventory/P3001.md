# Passport P3001 — Ivy-Bridge Xeon box, fleet's first local ISA-floor engine build

Live-collected 2026-11-02 (ssh; commands at bottom). Box re-commissioned with an
RTX 3060 on 2026-11-01; the ready-made Strata engine cannot run on this CPU
(AVX2 required), so the engine is compiled locally with the experimental
older-CPU floor — the first applied case of that path in this fleet.

**Video:** the monitor sits on the K620; the RTX 3060 has no connected
connector, so it is compute-only in practice. nvidia-smi and CUDA enumerate the
two cards in different orders; the engine's GPU auto-pick skips the unsupported
K620 on its own — do not pin a `gpu` index in the profile.

**First ladder (2026-11-02, engine cold right after the Qwen3.6 experiment —
worst-case page cache; 128-token answers, temperature 0):** prefill 41.9 tok/s
at 1,568 prompt tokens, plateauing at 189–193 tok/s at 6,168 and 12,268 (wall
41 s / 74 s); decode 14.1–15.0 tok/s cold, 19.1–20.8 warm. The box's weak spot
is SHORT prompts, not raw speed: the file tier amortises expert streaming over
prefill chunks of 2,048 tokens, so a 60-token prompt prefills at only
10.9–19.8 tok/s while 8k prompts run 10× faster per token. Raw ladder rows and
config: results/p3001-initial-benchmarks.md. Storage A/B the same day: serving
the whole stack off the Kingston SATA SSD (full copy under `/srv/strata`, cache
dropped) multiplies everything by 4–5 — prefill plateau 47 tok/s, cold decode
3.4, warm 7–8, a 12k prompt in 5 min. The engine itself reports `drive 0.45
GB/s` there. Verdict + full numbers: results/p3001-ssd-vs-nvme.md. Production
stays on the NVMe; the SATA copy is a standby.

**Contour harness v2.1 full sweep (2026-11-02):** 178 tasks, adjusted mean
0.972, perfect 90 %, task wall p50 21.8 s, engine decode p50 16.1 / p90 31.3
tok/s, 1,516 consumed tokens per perfect answer. Two G document-QA tasks are
capacity rejects for this box (113k-char documents > 32k context → HTTP 400);
every fitting G task scored 1.00. Full report: results/p3001-parb-v21.md.

**Change ledger:** hardware/changes/P3001.md — CHG-001 GPU swap in progress
(2026-11-02): pinned pre-swap state + post-swap re-benchmark checklist.

**Qwen3.6-35B-A3B UD-Q4_K_XL experiment (2026-11-02, published as a negative
result):** file 22,853,663,008 bytes, sha256 `55983c5a…fe9f1` (matches the
upstream digest). The q36 engine path keeps every expert it can in VRAM and
holds the whole expert set (18.75 GiB measured) in host memory — placement
completed in 156.5 s with 36/256 experts per layer resident (2.64 GiB VRAM),
but on 15.5 GiB RAM the first attempt was OOM-killed by the kernel (exit 137,
dmesg-confirmed). With a 24 GB swapfile the engine survives and runs in heavy
thrash (swap ≈ 10–13 GiB in use, iowait 83–87 %): three bench rounds gave
prefill 1.3–1.5 tok/s and decode 6.4–16.9 tok/s (33.6 % of batch expert rows on
GPU, 1,997 slot replacements) — a 200-token prompt would take minutes;
practically unusable on this box. Upstream's own floor for this size is
32 GB RAM. See history/failures/failures.md.

**Configuration history:** shipped without a compute GPU; RTX 3060 added
2026-11-01; driver 615.71.09 (Maxwell-unsupported, K620 unclaimed) replaced
2026-11-02 by 580.196.07 so both cards claim the NVIDIA driver. Engine dir
`engine-avx` alongside a prebuilt `engine/` kept for reference (refuses to
load on this CPU).
