# EXT-003 — second external critical audit (English translation)

Translated from the verbatim Russian text received 2026-11-01 (evening CET);
original archived in the `ext-records-2026-11-01-v2.tar.zst` release asset,

---

Overall score across 10 balanced criteria: **7.0/10** — a strong
experimental open-source project, but not yet a convincingly established
scientific study. Compared with the previous audit the repo grew
substantially: 223 objects in the public git tree instead of 176, extra
independent checks, archives, CI and a dashboard. Main conclusion:
*engineering maturity is growing faster than scientific evidential
strength* — normal for a young lab, but the difference must be understood.

Criterion scores: presentation 8, architecture/engineering 8, openness and
transparency 9, reproducibility 8 (independent full run not yet confirmed),
scientific methodology 6 (paired tests exist; strong external baselines and
a large holdout missing), evaluation independence 6 (second scorer appeared
and did not confirm the main gain on its coverage area), autonomy evidence 5
(good decision log, incomplete primary action history), reliability/security
7 (CI, isolation principles, privacy-gateway prototype; protection not yet
proven), novelty/interest 7 (open self-repair loop is interesting, the base
idea is already researched), practical applicability 6 (cheap hardware is
promising; external real tasks and cost-matched tests needed).

What genuinely improved: the 206-task holdout bank and 71-row pilot; the
second scorer that does not import the main scorer, with its dissent
published rather than hidden; the automatic publication pipeline with a
package index and public releases; successful CI runs and the GitHub Pages
dashboard; and publishing the previous criticism together with a response —
"rare and very useful practice".

Three most serious scientific problems:

1. **The second scorer did not confirm the main quality gain.** Harness
   +0.047 (229 improved / 79 regressed) vs independent −0.011 (13 / 22) on
   its coverage area. The scorers cover different aspects, so they are not
   directly equivalent — but the main positive conclusion lacks independent
   confirmation on the independently-scoreable subset. Not a refutation; a
   limitation to remove with a stronger evaluation.
2. **Real degradation on new tasks.** Holdout pilot: mean 81.9%, category G
   (long context) 16.7%, D 63.6%, 71 rows, one box, small sample. The G
   collapse shows mechanisms tuned to familiar templates may not transfer
   to new long documents. Positive: the project publishes the failure.
3. **The most important control experiment is missing.** Budget-matched
   comparisons against simple solutions are still only in the roadmap. The
   question a professional will ask: why an autonomously evolved harness if
   a plain validator, one extra request, or a few dozen lines of code give
   the same result? Until it runs, the complexity cannot be called justified.

Polish defects: README clone command points at the old `ViktorIXAI/autonomous`
and the next command `cd`s into the even older `strata-autonomous-harness`
directory — the first-time install path is broken as written;
`benchmarks/privacy-boundary/README.md` still says NOT implemented while the
gateway code and tests exist; several failed Actions runs in history with
unexamined causes; autonomy evidence still rests mostly on logs and
reconstruction — full primary transcripts are not published. "The first
command from the README must work without user guesswork."

Score comparison: previous 6.7/10 (6 criteria) vs current 7.0/10 (10
criteria, stricter) — approximately comparable, not a measured growth.

Final verdict: no longer an amateur repo built for flashy AI claims; a
serious engineering experiment with open data, failed versions, recomputation
tooling and first independent self-criticism. The strongest scientific claim
— that autonomous harness development yields a durable, cost-effective
improvement of local models — is not yet proven. Unusual merit: the repo now
contains its own evidence that some earlier optimistic results may have been
overstated; that transparency adds trust in the process even while lowering
the score of the results. Next real gains will come not from new harness
versions but from external tests, independent evaluation, and equal-budget
comparisons against simple alternatives.
