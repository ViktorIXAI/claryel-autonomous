## Mechanism (one substantive change, frozen now)

`H_UNKNOWN_PROMPT = contour_at_least(2, 54)` at registration — fires ONLY when the parsed H answer
HAS an `unknown` key whose value is null/empty, `actions_done` and `claims` are both empty, and the
prompt contains EXACTLY ONE denial sentence from a closed regex set; the value written is that
prompt sentence VERBATIM (quote-stripped) — every token comes from the task text, zero model
tokens, reference never read. Zero/multiple denial sentences refuse the whole prompt; a missing
`unknown` key refuses (never ADD a contract key); an already-filled slot emits
`v54_h_unknown_matched` byte-identically. After this pair the flag is redefined as
`STAMP_REVISION == (2, 54)` (the 2.30/2.31/2.32/2.34/2.36/2.41/2.42/2.44 freeze pattern);
`gate_v68` pins the freeze mechanically at the definition site.
