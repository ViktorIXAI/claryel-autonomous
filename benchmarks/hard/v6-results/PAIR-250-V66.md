## Mechanism (one substantive change)

`C_PY_GROUND = contour_at_least(2, 53)` — `gate_c_ground.ground_py_options` parses ONLY the
«печатает <literal>?» question plus contiguous `X: expr` option lines of a C prompt. Every option
must AST-parse inside a CLOSED allow-list (literal containers, slices, numeric +,-,*,/,//, pure
builtins over them); the match against the printed target is strict type+value equality. Free
names, comprehensions, attributes, keyword args, unsafe calls, second/missing target literals,
evaluation errors and non-contiguous letters refuse the WHOLE prompt. On a fire the contour
re-derives the letter set from what THIS prompt's snippets actually print and changes ONLY the
bytes of the model's own ОТВЕТ line; an already-equal set records `v53_c_py_matched` and leaves
the text byte-identical. The hidden reference is never read; zero model tokens.

Coverage was pinned BEFORE the pair by `harness/gate_v67_c_py_options_test.py` (108 checks): the
grammar parses EXACTLY {C-ex6-02} over all 77 v6.6 + all 77 v6.2 prompts; the derived set equals
gold on both banks; a counterfactual replay over all 27 published C-ex6-02 rows converts 27/27
with only the ОТВЕТ line changed, 0 mis-derivations; refusal branches hold on invented prompts;
the frozen 2.41 grammar still refuses this prompt.
