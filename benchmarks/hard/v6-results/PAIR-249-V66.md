## Mechanism (one substantive change)

`A_PCT_CHAIN = contour_at_least(2, 52)` — `harness/gate_run.py::_a_pct_chain` recomputes the
prompt's own percent chain by code: one `id=NUMBER` base, `len(keys)-1` «P% от <expr>, [но] не
более|не менее CAP» clauses, one parenthesized formula that binds clause order to spec-key order
(two independent prompt orderings must agree), inline «word NUMBER» constants. It refuses — text
untouched, no event — on any unknown token, order/count disagreement, word-vs-label collision, or
extra/non-numeric model key. The model's key SET is never changed; an already-equal answer is a
no-op; the reference is never read; zero model tokens. Event: `contour:v52_a_percent_chain`.
Dry-run pinned by `gate_v66_a_percent_chain_test.py` (100 checks): the grammar parses EXACTLY
{A-ex6-03} over all 77 v6.6 AND all 77 v6.2 prompts; its values equal the bank ref
(2090.0/1179.9/6230.1) — gold reproduced from printed rules; counterfactual replay over all 21
