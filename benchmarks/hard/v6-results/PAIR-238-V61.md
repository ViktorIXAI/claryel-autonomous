## Verdict

**`0.0.2.38` NOT adopted — the pair is UNMEASURED per the pre-registered rule (a).** The adopted line
did not fail its target cell in any control seed, so the pair contained no on-target measurement
opportunity; the arm delta +1.0 is below the resolution floor and is not quoted as evidence either way.
`A_TABLE_ARITH` stays frozen and is now pinned to the exact revisions `(2,33)` and `(2,38)` — it must
not ride into 2.39+ via a `contour_at_least` floor, the same inheritance discipline that froze
2.30/2.31/2.36 (`gate_v49` pin matrix). The control line stays `0.0.2.37`.

Process lesson, recorded because it is the second time (2.33 at pair-233, 2.38 at pair-238): a pair
built on a cell that *happened* to lose one pair's seeds can end up with zero live targets. A pair
candidate must be pre-registered against a **chronic** failure — a cell that fails in both arms of the
preceding pair or sits in the stable-fail set of the stability map — not against one arm's lottery
loss. `J-ex6-02` is exactly that: a stable fail in the six-seed map AND 0/6 in both arms of this pair,
every loss `order_partial` with the right id set in the wrong order.
