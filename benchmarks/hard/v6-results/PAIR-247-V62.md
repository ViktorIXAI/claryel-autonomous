## Mechanism (one substantive change)

`want_fields(prompt)` (the K/`KEY: value` completeness detector, line behavior since 2.23-era wiring)
scans the prompt for UPPERCASE tokens followed by a colon. A K prompt's only colon-suffixed
UPPERCASE tokens are the instruction's own example — `верни ровно 4 строк вида FIELD: значение` — plus
an optional parenthetical value form. So for `K-ex6-03` the required key set was
`[FIELD, FREE_SHIPPING]`, the contour hint (`ВЫВЕДИ строки вида КЛЮЧ: значение ровно для таких
ключей: …`) told the model to use the literal placeholder `FIELD` as a key, and the gate accepted the
result with `gate:fields_ok`.

`0.0.2.48` adds `fields_enumeration(prompt)` — the field names the task prints on its own `Поля:` line
(UPPERCASE identifier tokens only; parentheticals, Cyrillic/lowercase/numeric fragments dropped,
dedup) — and `fields_required(prompt)` replaces the old set **only when the prompt enumerates fields
AND the old detection is placeholder-tainted** (`FIELD`/`KEY`/`КЛЮЧ`/`КЛЮЧИ`/`NAME`/`ИМЯ`);
non-placeholder old keys are kept. Reference (`ref`) is never read. `want_format`, which decides
whether the gate runs at all, keeps calling the untouched `want_fields`, so the live surface is closed
by construction. Event: `contour:v48_fields_enum_from_prompt:<n_keys>`, fired only where the set
actually changed.

Contract: `harness/gate_v62_k_field_enum_test.py` (130 checks — grammar incl. invented field names,
the taint condition in both directions, per-stamp flag matrix, `want_format` surface invariance over
all 77 bank prompts, live `fields_gate` drives at both stamps), `gate_v49` extended (69 checks:
2.48 == 2.47 + exactly `K_FIELDS_ENUM`). Full CI contract list green locally under python3.12;
`gate_v62` enrolled in `.github/workflows/scoring-contracts.yml` in the same commit.

## Adoption

Pre-registered rule: ADOPT iff (a) MEASURED AND >=1 evented conversion AND all guards clean. All
three hold on the strongest possible form (3/3 conversions, 0 guard violations) -> **0.0.2.48
ADOPTED**, `K_FIELDS_ENUM = contour_at_least(2, 48)` inherits as line behavior (`gate_v49` pin:
2.48 == 2.47 + exactly `K_FIELDS_ENUM`).

Queue after this pair, in priority order:
1. **Bank v6.3**: `B-ex6-04` still fails 9/9 and is a published bank defect (cadence-246 root cause:
   the gold `start_date` year `2026-04-01` is never stated in the prompt; seeds answer 2023/2024/2025

   is already spent (pair-246 lesson). Their instability is now published three pairs running, so the
   next honest step is a variance-reduction protocol (replicated cells + pooled sign test at the
   *cell* level), not another selection trigger.
4. Measurement stack P0 continuation: seed-protocol verification across published reps and rescore
