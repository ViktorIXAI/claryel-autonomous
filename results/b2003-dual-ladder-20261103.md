# B2003 dual-channel context ladder — express series (2026-11-03)

Post-CHG-001 validation (2× 24 GB DDR5-5600 back, dual channel, 47321 MiB usable;
RTX 3060 returned from the P1005 loan). Express ladder against the live
:8080 serve, engine 0.1.52, IQ3_S, ctx 32768. Raw rows: hardware/changes
reference only; raw jsonl+sampler live on the box (`~/parb/ladder-dual-20261103*`).

## Method

Prompt rungs ~1k/4k/8k/16k/30k tokens, each prompt salted with a fresh uuid
(no cross-rung prompt-cache hits), max_tokens 128, temperature 0. Cold rows:
`sync + drop_caches` + 2 s before each ask. Warm-steady rows: no cache drop,
fresh salt. Prompt-cache pair: identical bytes twice. 3 s GPU/RAM sampler in
parallel (48 samples). Same engine accounting (`timings`) as fleet ladders.

## Comparison and verdict

- Decode 60–75 tok/s sits inside the published steady band for this box
  (60–68, results/baselines.md era) — **norm**, unchanged by the DIMM event.
- Prefill plateau at today's profile is ~390–400 tok/s (cold) / ~400 (steady).
  The dual-channel-era baseline of 2026-10-30 (bench/2026-10-30-b2003,
  REPORT-ru.md §3) showed 865–914 tok/s at 8k–30k — but that profile ran
  `--resident-budget-gib 24 --conversation-cache-mib 1536` plus
  `STRATA_UNBUFFERED_LOAD=1 STRATA_RESIDENT_HEADROOM_GIB=10`, i.e. it is NOT
  the same serve config. Today the launch profile still carries the
  single-DIMM-era arena 13 / cap 16384 / cache 512 (backup of the old
  24-GiB variant exists on the box: `~/Strata/run-iq3_s-3060.sh.bak-24gib-reserve`).
- Verdict: RAM capacity and channel state restored and stable under load;
  prefill is capped by the still-single-channel-era serve profile, not by the
  memory itself. Restoring the 24-GiB-reserve profile and re-running this same
  ladder is the next step when the box comes back for fleet benchmarking
  (expected to bring the 800–900 t/s band back — unverified until re-run).
